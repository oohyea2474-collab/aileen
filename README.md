# ☕ Cafe Aileen

가상의 동네 카페 **"카페 아일린"**을 소개하는 한 페이지짜리 랜딩 페이지입니다.
HTML, CSS, JavaScript만으로 만들었고, 따로 설치하거나 빌드할 것이 없습니다.

🔗 **사이트 바로 보기:** https://oohyea2474-collab.github.io/aileen/

---

## 📁 폴더 구성

```
aileen/
├── index.html      # 페이지 구조 (내용과 뼈대)
├── css/
│   └── style.css   # 디자인 (색상, 글꼴, 배치, 모바일 화면)
├── js/
│   └── script.js   # 동작 (메뉴 탭, 영업 상태, 스크롤 효과 등)
└── README.md       # 지금 보고 있는 설명 문서
```

| 파일 | 역할 | 비유 |
|------|------|------|
| `index.html` | 화면에 무엇이 들어갈지 정합니다 | 건물의 뼈대 |
| `css/style.css` | 어떻게 보일지 꾸밉니다 | 인테리어 |
| `js/script.js` | 클릭·스크롤에 반응하게 합니다 | 전기와 배선 |

`index.html`이 아래 두 줄로 CSS와 JS 파일을 불러옵니다. 그래서 파일이 폴더 안에 있어도 정상으로 동작합니다.

```html
<link rel="stylesheet" href="css/style.css">
<script src="js/script.js"></script>
```

> 폴더 이름을 바꾸거나 파일을 옮기면 위 경로도 같이 고쳐야 합니다.

## 🧩 페이지 구성

페이지는 위에서 아래로 다음 순서로 되어 있습니다.

1. **상단 메뉴(헤더)**: 로고와 `소개 · 메뉴 · 오시는 길` 링크입니다. 스크롤해도 화면 위에 고정됩니다.
2. **메인 화면(히어로)**: 커피 사진 배경 위에 카페 이름, 한 줄 소개, `메뉴 보기` 버튼이 있습니다.
3. **소개(ABOUT)**: 카페의 특징 3가지(직접 로스팅, 매일 굽는 디저트, 편안한 공간)를 카드로 보여 줍니다.
4. **대표 메뉴(MENU)**: 커피 4종과 디저트 2종의 이름, 설명, 가격입니다.
5. **오시는 길(VISIT)**: 영업시간과 위치, 연락처입니다.
6. **푸터**: 저작권 문구입니다.

## ✨ 기능 (`js/script.js`)

| 번호 | 기능 | 설명 |
|:---:|------|------|
| 1 | 모바일 메뉴 | 화면 폭이 600px 이하이면 상단 메뉴가 ☰ 버튼으로 바뀌고, 누르면 펼쳐집니다. 메뉴를 고르면 자동으로 닫힙니다. |
| 2 | 헤더 그림자 / 현재 메뉴 강조 | 스크롤을 내리면 헤더에 그림자가 생기고, 지금 보고 있는 섹션의 메뉴 글자색이 바뀝니다. |
| 3 | 메뉴 탭 | `전체 / 커피 / 디저트` 탭을 눌러 메뉴를 종류별로 볼 수 있습니다. |
| 4 | 영업 상태 표시 | 접속한 시각을 보고 "지금 영업 중이에요" 또는 "지금은 영업 시간이 아니에요"를 표시합니다. |
| 5 | 스크롤 등장 효과 | 카드와 제목이 화면에 들어올 때 아래에서 부드럽게 떠오릅니다. |
| 6 | 연도 자동 표시 | 푸터의 연도가 올해로 자동으로 바뀝니다. |

- 영업 상태는 **방문자 컴퓨터의 시계**를 기준으로 계산합니다.
- 영업 시간 기준: 평일 08:00–21:00, 주말 10:00–22:00, 월요일 휴무
- 컴퓨터에서 "애니메이션 줄이기"를 켠 방문자에게는 스크롤 효과를 보여 주지 않습니다.

## 🎨 디자인

- **색상**: 크림색 배경에 커피 브라운을 강조색으로 썼습니다. 색은 `css/style.css` 맨 위 `:root`에 모여 있어서 한 곳만 바꾸면 페이지 전체 색이 바뀝니다.

  ```css
  :root {
    --bg: #faf6f0;        /* 배경색 */
    --accent: #a0613a;    /* 강조색 (버튼, 가격) */
    --text: #3b2a20;      /* 글자색 */
  }
  ```

- **글꼴**: Google Fonts의 `Noto Serif KR`(제목)과 `Noto Sans KR`(본문)을 씁니다.
- **반응형**: 컴퓨터, 태블릿, 휴대폰 화면에 맞춰 카드 배치가 자동으로 바뀝니다.
- **이미지**: 메인 배경 사진은 Unsplash 이미지를 주소로 불러옵니다.

## ✏️ 내용 바꾸는 법

| 바꾸고 싶은 것 | 고칠 파일 | 찾을 곳 |
|------|------|------|
| 카페 이름, 소개 문구 | `index.html` | `<section class="hero">` |
| 메뉴 이름, 가격 | `index.html` | `<div class="menu-item">` |
| 메뉴 추가 | `index.html` | `menu-item` 한 줄을 복사해서 붙여넣기 (`data-category`는 `coffee` 또는 `dessert`) |
| 주소, 전화번호 | `index.html` | `<section id="visit">` |
| 영업 시간 계산 | `js/script.js` | 4번 주석 `지금 영업 중인지 표시` |
| 색상 | `css/style.css` | 맨 위 `:root` |
| 배경 사진 | `css/style.css` | `.hero`의 `url("...")` |

> ⚠️ 영업 시간을 바꿀 때는 `index.html`의 안내 문구와 `js/script.js`의 계산을 **둘 다** 고쳐야 화면 표시가 맞습니다.

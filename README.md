# Cafe Aileen

간단한 카페 랜딩 페이지입니다. `index.html`을 브라우저에서 열면 바로 볼 수 있습니다.

## 폴더 구성

```
aileen/
├── index.html      # 페이지 구조
├── css/style.css   # 디자인
└── js/script.js    # 동작
```

## 기능

- 소개 / 대표 메뉴 / 오시는 길 섹션
- 메뉴 탭 (전체 / 커피 / 디저트)
- 현재 시각 기준 영업 중 여부 표시
- 스크롤 시 헤더 그림자, 현재 섹션 메뉴 강조, 부드럽게 나타나는 효과
- 모바일 햄버거 메뉴
